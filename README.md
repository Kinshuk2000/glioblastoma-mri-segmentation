# Glioblastoma MRI Tumor Segmentation and Prediction Analysis

## Overview

This project focuses on multi-slice glioblastoma tumor segmentation using T1-weighted contrast-enhanced MRI scans. The work demonstrates preprocessing, segmentation visualization, contour comparison, and performance evaluation using biomedical imaging techniques.

## Objectives

* MRI preprocessing
* Tumor segmentation
* Ground truth comparison
* Overlay visualization
* Segmentation performance evaluation

## Tumor Regions

* Enhancing Tumor
* Necrosis
* Edema

## Performance Metrics

* Dice Similarity Coefficient (DSC)
* Intersection over Union (IoU)
* Sensitivity
* Specificity
* Precision

## Visualization Results

The repository includes:

* Original MRI scans
* Preprocessed MRI scans
* Ground truth segmentation masks
* Predicted segmentation overlays
* Multi-slice comparison visualizations
* Tumor contour analysis

## Tools and Technologies

* Python
* NumPy
* Matplotlib
* OpenCV
* Biomedical Imaging Techniques

## Future Scope

* Deep learning segmentation models
* MRI radiomics analysis
* Survival prediction modeling
* Neuroimaging AI applications
* Brain-Computer Interface (BCI) integration
